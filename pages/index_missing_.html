What do we mean by missing?

Missing files are those for which I’m unable to get match data in the period the site attempts to cover. For example T20 Internationals have been played since 2005, so any missing entries are matches that have taken place from 2005 to the present day. We also only include Tests matches, One-day internationals, and matches from club competitions we cover (such as the Big Bash League), and exclude other matches types, as some match types are too extensive to keep track of easily.

Missing entries doesn’t include matches from a period before the one we’re covering, so Test matches in the 1920s aren’t regarded as missing but will be if we ever start attempting to cover the period. That doesn’t means you can’t get in touch with details of matches that aren’t regarded as missing, if you have the information we’d be delighted to hear about it!
